## Context

The second of plan-043's three tasks (ruling N, 2026-10-21): the rest of `base`'s workflows and its
AGENTS.md section, from the accepted charter `pack-foundation-base`, on top of task-037's smallest
valid `base` (merged `b6e9755`). It also settles the charter's open point 0.

**Open point 0, read at `wingfoil/wingfoil@v0.3.0`:** a workflow's actions are free-form strings the
agent runs (`src/workflow/schema.ts`), so `memory.add(type: decision-log, tags: [retrospective])`
is accepted and run as an add with that tag (WingFoil's `memory add --tags`); a phase's `where`
matches a list field by a shared element (`matches`, `src/workflow/deduce.ts`), so
`where: { type: decision-log, status: [in-discussion], tags: [retrospective] }` selects the
retrospective's decision-log only. The charter's selection holds; this task records the outcome in
the charter's Execution Notes and closes the open point.
