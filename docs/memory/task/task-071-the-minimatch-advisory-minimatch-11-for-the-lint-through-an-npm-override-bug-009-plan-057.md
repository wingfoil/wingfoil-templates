## Context

bug-009 (major): the minimatch advisory GHSA-g3hv-75wg-m249 (`<11.0.1`, moderate) fails the CI's
root audit on every branch and on `main`. `minimatch` is a development dependency only, through
`eslint`, `@eslint/config-array` and `typescript-eslint`, which all require `^10.2.x`: no lockfile
move within their ranges fixes it (bug-003's and bug-004's way). The approver ruled on 2026-10-31 an
npm `overrides` entry pinning `minimatch` to 11 for the whole tree, before task-070's gate, pinned
exact as adr-002 requires; if it fails a check, this task stops and the approver rules a CI policy
instead. A probe on a scratch clone of `main` found `npm audit` 0 and `npm run lint` 0 with it.

## Acceptance

As task-043, a dependency-only change, with no code and no test: dl-018 R1's test does not apply,
since a test asserting a transitive version would duplicate `npm audit`, which needs the network
(the `testing` directive keeps tests offline), and would go stale at the next advisory. The red
and green are `npm audit`'s exit codes, recorded with the command and its output.

1. **Red** (recorded): on `main`, `npm audit` in the root exits 1 ("11 moderate severity
   vulnerabilities", GHSA-g3hv-75wg-m249), and in every `src/matrix/wingfoil-*/` exits 0; the CI's
   first red run on `main`, 41196364111 (`77510f3`), cited.
2. **The fix:** `package.json` gains `"overrides": { "minimatch": "11.0.3" }`, an exact version
   (adr-002, adr-003, `determinism`), with no other change to it, and `package-lock.json` is
   regenerated by `npm install --package-lock-only --ignore-scripts`; the fix commit's diff is those
   two files (3 and 16 lines): `minimatch` 10.2.6 → 11.0.3, `@isaacs/nonrecursive-glob-match` 1.0.3
   added, `minimatch`'s declared `brace-expansion` range raised to `^5.0.12` (5.0.12 locked as
   before). No direct dependency's version, matrix lockfile, runtime dependency (adr-003) or
   `.wingfoil/dna.yaml` changes. If the lockfile moves anything else, it goes to the approver
   (dl-019) before any other approach.
3. **The checks of a dependency change:** after `npm ci`, `npm ls minimatch` shows 11.0.3 on every
   path and no `invalid` or `ERR` line; `npm audit` exits 0 in the root and in every
   `src/matrix/wingfoil-*/`; `npm audit signatures` verifies (its counts recorded, 190 with
   signatures and 43 with attestations when reviewed); the licences recorded (`minimatch` 11.0.3 and
   `@isaacs/nonrecursive-glob-match` 1.0.3 BlueOak-1.0.0, as `minimatch` 10.2.6's); `npm run lint`
   exits 0, and the config's patterns, which go through `minimatch`, still match as before, in a
   scratch copy: the linted file list (`eslint --format json .`) identical with 10.2.6 and with
   11.0.3, a `Date.now()` in a scratch `src/*.ts` reported by the determinism rule
   (`no-restricted-properties`, exit 1), and the same in a scratch file under `tests/fixtures/`
   ignored.
4. **Green:** from clean clones on Node.js 22.21.0 and 22.12.0, one after the other: `npm ci`,
   `npm test`, `npm run lint`, `check:pins`, `check:schemas`, `check:packs`, `validate`, the
   overlays `software-exit` and `scrum-exit`, `index -- --check`, `check:runs` and `workflow list`
   exit 0; the CI run on the branch is `success`, both jobs, its audit steps run and passed,
   recorded; the privacy check of the branch's diff recorded.
5. **After the merge:** `main`'s CI is `success` and recorded in bug-009's notes; the owed row "CI
   policy for advisories in transitive dependencies" stays open (the override answers this
   advisory, not the policy), its note citing bug-009; two owed rows (owner approver, trigger: the
   next dependency update): the override's removal, once `eslint`, `@eslint/config-array` and
   `typescript-eslint` accept `minimatch` 11 (until then the override forces every `minimatch` of
   the tree onto 11.0.3, a later dependency needing another major included, with no warning); and
   `check:pins` covering `overrides`, which it does not read today (`src/check-pins.ts`, its
   dependency fields).

## Design

Branch `task/task-071-minimatch-override` from `main`. A dependency-only change (task-043's kind):
the red `npm audit` on `main`; `"overrides": { "minimatch": "11.0.3" }` added to `package.json` by
hand, then `npm install --package-lock-only --ignore-scripts`; `npm ci`; the checks of
Acceptance 3, the lint probes in a scratch clone (the linted file list with 10.2.6 and with 11.0.3,
the two `Date.now()` probes); the clean clones; the branch CI. Commits: the fix (the two files);
the notes; the owed rows (Acceptance 5) with the delivery.
