# WingFoil template catalog

The packs of the official WingFoil template catalog, by axis, with their presets, transitions
and the adoption profiles they serve. This file is generated by `npm run index` from
`catalog.yaml`, `compat.yaml`, the presets and each published version's tag: do not edit it
by hand.

## For agents

Agents read the catalog with no server, through anonymous URLs; [llms.txt](llms.txt) is their
entry point.

- the index: `https://raw.githubusercontent.com/wingfoil/wingfoil-templates/main/catalog-index.json`
- a published version's README: `https://raw.githubusercontent.com/wingfoil/wingfoil-templates/refs/tags/<catalog pack id>@<version>/packs/<catalog pack id>/README.md`
- a published version's manifest: `https://raw.githubusercontent.com/wingfoil/wingfoil-templates/refs/tags/<catalog pack id>@<version>/packs/<catalog pack id>/pack.yaml`
- resolution: `https://raw.githubusercontent.com/wingfoil/wingfoil-templates/main/catalog.yaml`
- compatibility: `https://raw.githubusercontent.com/wingfoil/wingfoil-templates/main/compat.yaml`
- a preset: `https://raw.githubusercontent.com/wingfoil/wingfoil-templates/main/presets/<id>.yaml`
- a transition: `https://raw.githubusercontent.com/wingfoil/wingfoil-templates/main/transitions/<id>.yaml`
