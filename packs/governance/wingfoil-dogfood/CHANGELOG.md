# Changelog

- 1.0.0: first version: the channel that turns a feedback item routed to `upstream:wingfoil` into a
  note in WingFoil's format, and the rules of running the project's pinned WingFoil CLI. It ships
  the directives `wingfoil-cli` and `wingfoil-channel`, the inbox and entries paths and the CLI
  command as parameters.
