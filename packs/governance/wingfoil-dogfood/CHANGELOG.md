# Changelog

- 1.0.0: first version: the channel back to WingFoil and the rules of the pinned WingFoil CLI.
  It ships the directives `wingfoil-cli`, the rules of running the project's pinned WingFoil CLI,
  and `wingfoil-channel`, which turns a feedback item routed to `upstream:wingfoil` into a note in
  WingFoil's format; the inbox and entries paths and the CLI command are parameters.
